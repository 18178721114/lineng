# 力能用工日报系统

把纸质《出勤表》+ Excel 考勤表/结算单搬上线：Vue3 H5（手机适配）+ Go + MySQL。

## 启动（两个终端）

### 1. 后端（端口 8090，自动建库建表 + 种子账号）
```bash
cd backend
go build -o lineng-server ./cmd/server && ./lineng-server
# 或直接 go run ./cmd/server
# 日志: /tmp/lineng-server.log (nohup 启动时)
```
工程结构（按模块分层）：
```
backend/
├── cmd/server/        # 程序入口
├── configs/           # 配置加载（环境变量，见 .env.example）
├── db/                # 数据库连接与种子数据
├── internal/
│   ├── model/         # 领域模型
│   ├── handler/       # 各业务模块处理器（auth/project/worker/report/stats/export）
│   └── router/        # 路由装配
└── pkg/               # 可复用基础包（jwt/middleware/resp）
```
- MySQL：127.0.0.1:3306，root/199361，库名 `lineng`（不存在会自动创建）
- 默认管理员：**admin / admin123**（首次启动自动创建）
- 如端口 8080 被占用属正常，本系统用 **8090**

### 2. 前端（端口 5173，/api 代理到 8090）
```bash
cd frontend
npm install   # 首次
npm run dev
```
浏览器/手机访问 http://localhost:5173 （局域网手机访问 http://<本机IP>:5173）

## 功能清单（对应 PRD docs/PRD.md）
| 模块 | 说明 |
|------|------|
| 登录 | JWT 7 天免登，未登录跳转 |
| 项目 | 对照纸质出勤表：用工单位/活动名称/地点/甲方负责人/电话/起止日期，编号 No. 自动生成（LN-YYYYMMDD-XXX） |
| 人员 | 姓名自动转**拼音全拼+首字母**，支持汉字/拼音/首字母搜索（如 zs → 张三） |
| 日报 | 每项目每天一单：①用工名单（**先填时间段，再选人**，弹窗内可快捷新建人员）②白天/晚上/凌晨人数（可按名单一键带出）③餐费（早点/中餐/晚餐/夜宵+**水**）④设备台班：叉车**3/5/7吨**（1吨已改7吨）+**吊车**+**救援车**×白/晚/凌晨 ⑤外包（人数+**加班时间**）⑥备注 |
| 统计 | 卡片（日报数/人次/工数/参与人数）+ 人员出勤排行 + 项目汇总 + 日报明细 |
| 导出-结算单 | 结构对齐《本地（北京）结算单-刘冬艳.xls》：人工→餐费含水→叉车3/5/7吨(算式行)→吊车→救援车→税费6%→劳务总合计；单价全部可参数化（默认取项目配置） |
| 导出-考勤表 | 结构对齐《2026年4月-12月考勤表》：Sheet「m月份」，行=人员按拼音排序，列=1~31，格=当日工数 |

## 已知边界（V1）
- 同一天重复提交 = 编辑该单（一天一单）
- 外包数据记录/展示于统计明细，暂不进结算单（模板无此区块）
- 住宿费未纳入结算单（PRD Out of Scope）
