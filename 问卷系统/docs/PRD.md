## 1. 背景与目标

**业务背景**：北京力能艺术文化服务有限公司目前用纸质《出勤表》（扫描件见 12a6d2ee-...png）+ Excel（考勤表、结算单）手工记录项目用工、餐费、设备台班，月底人工汇总易错、慢、难统计。

**产品目标**：把"纸质出勤表 + 两张 Excel"搬线上：
1. 项目创建后每天手机填一张用工日报（5 分钟内完成）；
2. 一键导出与现有 Excel 模板一致的【结算单】和【考勤表】；
3. 人员、工时、餐费、设备台班自动统计。

**用户画像**：现场负责人（手机填报）、结算/管理员（登录后台、导出对账）。

## 2. 范围定义

### In Scope（本期）
1. **登录**：后台一套管理员账号（admin），JWT 鉴权；H5 与后台共用。
2. **项目创建**：对照纸质出勤表字段——用工单位、活动名称、地点、甲方负责人、甲方电话、用工时间（起止日期）、单据编号 No.（系统自动生成）、状态。
3. **人员管理**：创建人员（姓名、电话、工种、备注），**姓名自动转拼音全拼 + 首字母**，选人时支持按汉字/拼音/首字母模糊搜索。
4. **用工日报（按 项目+日期 一单一编辑）**：
   - ① 用工名单：**先填工作时间（开始~结束），再选人名**（可多选，支持拼音搜索）；
   - ② 用工：白天/晚上/凌晨人数（按名单自动带出，可改）；
   - ③ 餐费：早点/中餐/晚餐/夜宵 + **水**（新增）；
   - ④ 设备台班：叉车 **3吨/5吨/7吨**（1吨改为7吨）、**吊车**（新增）、**救援车**（新增）× 白班/晚班/凌晨；
   - ⑤ 外包：是否外包 → 外包单位（名称 + 白/晚/凌人数 + **加班时间**（新增，起~止）），可加多套；
   - ⑥ 备注。
5. **导出-结算单**：选项目 + 日期区间 + 各项单价（人工元/人；早点/中餐/晚餐/夜宵/水 元/份；叉车3/5/7吨、吊车、救援车 元/台班；住宿费可选；默认税率 6%），生成 xlsx，结构对齐《本地（北京）结算单-刘冬艳.xls》：人工明细 → 餐费+水明细 → 叉车3/5/7吨台班明细与金额算式 → 吊车 → 救援车 → 合计 → 税费 → 劳务总合计。
6. **导出-考勤表**：选项目 + 月份，生成 xlsx：行=人员姓名（按拼音排序），列=1~31 日，单元格=当日工数（按用工名单出勤记 1，加班等由名单时间覆盖），合计列，按月分 Sheet。
7. **数据统计**：总览卡片（日报数、用工总人次、总工数、参与人数）；按人员（出勤天数/工数排行）；按项目（人次、餐费、设备台班）；日报明细表。

### Out of Scope（本期不做）
- 多角色权限、审批流；微信/短信登录；住宿费录入（结算单中作为可选参数项）；数据大屏。

## 3. 用户故事（关键）

| 角色 | 动作 | 价值 | 验收标准 |
|------|------|------|----------|
| 管理员 | 登录 | 安全使用 | 1. 账密错误提示明确 2. 登录后 7 天内免登 3. 未登录访问接口返回 401 |
| 管理员 | 创建项目 | 建立填报归属 | 1. 必填：用工单位/活动名称/地点/甲方负责人/起止日期 2. 编号 No. 自动生成（LN-YYYYMMDD-序号）3. 项目卡片显示周期与进度 |
| 管理员 | 创建人员 | 建立名单 | 1. 姓名必填、查重 2. 保存后可用拼音全拼（zhangsan）或首字母（zs）搜到 3. 可编辑/停用 |
| 现场负责人 | 填日报 | 5 分钟完成 | 1. 项目/日期自动带出 2. 用工名单先选时间段再选人 3. 各班次人数自动带出可改 4. 外包选"是"才显示外包块 5. 重复提交同一天为编辑 |
| 管理员 | 导出结算单 | 对账 | 1. xlsx 结构与模板一致 2. 金额=数量×单价，合计、税费6%、总额公式正确 3. 无数据的日期行留空 |
| 管理员 | 导出考勤表 | 记工 | 1. 行=人员、列=当月 1~末日 2. 出勤日=当日名单工数 3. 合计列正确 |
| 管理员 | 看统计 | 掌握全局 | 1. 卡片+排行+明细三层 2. 与导出数字一致 |

## 4. 非功能需求
- 手机 Safari/微信内置浏览器与 Chrome 可用；页面 375px 宽度优先自适应。
- 接口响应 ≤ 500ms（本地）；密码 bcrypt 存储；token 过期 7 天。
- 后端启动自动建库建表（首跑零配置）。

## 5. 风险
| 风险 | 应对 |
|------|------|
| 生僻字拼音转换不准 | go-pinyin 兜底原字，可手改搜索串 |
| 导出与客户模板细节差异 | 按模板逐区块复刻；单价全部参数化 |
| 一天多单需求 | V1 一天一单，字段"备注"可补充说明 |
